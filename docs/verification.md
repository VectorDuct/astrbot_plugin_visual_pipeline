# 验证范围

日期：2026-11-13。版本：v0.1.0 发布候选。

## 已验证

在临时 `soulter/astrbot:v4.29.1` 容器内，用 Python 3.12、aiohttp 3.14.5、Pillow 13.0.0 运行 **24 项离线测试，全部通过**。容器断网、内存上限 512 MiB、1 CPU；仅只读挂载项目源码，不挂载机器人运行目录、密钥或会话。SDK 临时初始化目录在容器内，退出即删除。

覆盖：

- 配置默认关闭、白名单为空、非法类型与地址拒绝；非授权群、私聊、其他适配器和非指令不调用 API。
- 真实 SDK 命令过滤器与唤醒前缀规范化兼容；真实 SDK 的图片消息组件构造。
- 提示词长度、附图/引用拒绝、附加词表、缺失密钥/消息身份。
- 同消息去重、用户冷却、并发仅受理一个任务、受理回复失败不生成。
- 接口失败和回复失败不重新生成，错误不回显接口正文或密钥。
- 终止取消在途任务，受理回复期间终止不启动新任务。
- 本地假 HTTP 接口精确请求字段、单张 Base64 图片、拒绝重定向/外部图片链接/超大响应/错误 JSON/多图/压缩响应，超时与取消不自动重试。
- 真实插件入口 → 本地假 HTTP Images API → 原消息事件图片回复的完整离线链路；请求中不包含群来源、用户标识和消息 ID。

源码归档还按明确文件清单制作，并检查归档路径、链接、文件哈希及已知私有部署标识和凭据格式。该检查不代替后续新增文件审阅。

## 未验证

没有发起真实模型生成，没有发送 QQ 消息，没有更改现有机器人或其他服务。真实服务商兼容性、实际图像质量、被动回复窗口、QQ 媒体发送/平台审核、内容审核效果与实际计费仍需部署者在自己授权的测试环境确认。本项目不是已上线商业服务或已获平台认证的证明。

可复现的测试命令见 README；CI 使用同一套离线用例。
