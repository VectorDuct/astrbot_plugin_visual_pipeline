# Visual Pipeline Connector

**工作流连接器 / Workflow Connector**

Visual Pipeline Connector 将 QQ 群中的显式绘图指令连接到管理员配置的图像 API，提供群来源白名单、单任务执行、请求去重、用户冷却、请求超时和有界图像响应校验。使用者配置自己的 API 端点与凭据，插件默认关闭。

Visual Pipeline Connector connects explicit image-generation commands in authorized QQ groups to an operator-configured Images API. It provides scoped access, single-job execution, in-memory deduplication, per-user cooldowns, request timeouts and bounded image validation.

安装与配置见 [中文指南](../README.zh-CN.md) 或 [English README](../README.md)。
