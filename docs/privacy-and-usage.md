# 数据与使用边界

## 数据流

仅在授权群的用户发送显式指令并通过检查后，文字描述、模型与尺寸会提交到管理员配置的图像服务。群来源、发送者标识和消息 ID 仅用于本地授权/限流/去重，不放入图像 API 请求。图像结果通过原 QQ 消息事件回复，在原群中可见。

本插件不持久化提示词、图片、会话或身份，不下载头像或读取其他成员信息；受理缓存与限流表只在进程内。重启或缓存淘汰会失去去重记忆，因此不能保证跨重启的恰好一次调用。API 密钥由进程环境读取，仅发给管理员指定的接口；不跟随重定向，不读取环境代理/netrc。

AstrBot、QQ 平台、服务商和部署方可能另有日志及数据保留策略，本插件无法代表它们承诺零留存。部署前应检查整个链路的日志配置，并向群成员说明用途、可见范围、服务商和费用。不要发送密码、个人证件或未经授权的个人信息。

## 内容和费用

插件不提供完整内容分类器。可选 `deny_terms` 仅作 Unicode NFKC + 忽略大小写的子串匹配，容易误伤或漏检，不等于审核通过、侵权检测或平台批准。部署方应结合实际服务商的审核能力与群管理要求决定开放范围；服务拒绝时直接失败，不替换服务或改写提示词绕过拒绝。

不要用词语替换掩饰实际能力或用户用途，不宣传无审核、绕过限制、无限免费、未获授权的账号接入或身份冒用。项目名称不代表腾讯、AstrBot 或任何模型服务商背书。

每次已受理的请求可能计费。超时、取消、图片校验失败或 QQ 发送失败，都不能证明上游没有完成或收费。插件不会自动重试/切换上游。管理员仍须在服务商侧设置配额和预算；插件没有持久化账单与全局日预算。

## 技术限制

- 文字最多 3000 字；单张图最多 12 MiB、2000 万像素；JSON 响应最多 17 MiB。不接受动画或外部图片 URL。
- 每个插件实例最多一个生成任务，无排队；本进程最近 256 条受理消息去重，同群同用户冷却 1–86400 秒。
- 请求总超时 10–600 秒，默认 180 秒。QQ 平台被动回复时限和媒体支持可能更严格；需要实际测试群验证，失败不主动跨会话补发。
- 不包含图生图、头像获取、引用图、提示词润色或聊天模型自动工具调用，也不提供其他群成员身份查询。
- 本次仅提供源码发布准备；没有进行真实模型生成、QQ 消息发送、平台审核、商标或法律审查。上线运营前需按实际平台与地区要求另行确认。
